# AutoQuaerere

Chromium/Edge search-link automation extension by **noviciususor**.

## v1.1.0
- noviciususor palette UI
- random 3–5 word search generation
- persistent generated-link queue
- manual sequential opening
- RUN BOT / STOP BOT automation
- Manifest V3 background service worker
- 5–8 second randomized interval using `chrome.alarms`

## Install
1. Extract the ZIP.
2. Open `edge://extensions` or `chrome://extensions`.
3. Enable Developer mode.
4. Choose **Load unpacked**.
5. Select the `AutoQuaerere` folder.

Use automation only where permitted by the relevant website/service terms.
